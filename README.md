# ♻️ 3R 分类工坊

给六年级学生的 3R（Reduce 减少使用、Reuse 重复使用、Recycle 回收）互动学习小游戏，中文版。

## 玩法（4 个关卡）
1. **分类拖拽**：把物品或动作拖进正确的 R 回收箱
2. **泡泡捕捉**：点破属于目标 R 的泡泡，点错扣分
3. **能回收吗？**：向右滑＝能回收，向左滑＝不能回收
4. **3R 旅程**：按“购物前、使用中、丢弃前”的顺序排好卡片

## 使用
纯 HTML 单文件，无需安装，直接双击 `index.html` 即可游玩。

## 部署到 GitHub Pages
Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` 和 `/ (root)`，保存后等一两分钟即可访问。

## 修改题目
打开 `index.html`，找到 `BANK`（分类题和泡泡题）、`SW`（能回收吗）、`SQ`（3R 旅程）三个列表，照着格式增加即可。
